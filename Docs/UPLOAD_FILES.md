# 上傳文件

判斷私人案還是公家案?
一上傳後，自動偵測 (AI 掃描 BOD 或 RFP 時，應尋找以下關鍵字)
1. Client Type: Public Works, School District, City of..., Dept of…
2. Funding Source: Federal Grant, State Bond.
3. Keywords: "DIR", "Davis-Bacon", "Certified Payroll", "Prevailing Wage".

私人案
1. 做什麼項目？
2. 該項目的什麼種類？
e.g. warehouse: 一般倉庫、科技廠倉庫、data center?
e.g. office: 一般 office、中階 office、高級 office?
e.g. health center: 什麼等級？
e.g. 無塵室: 什麼等級？
3. 新建 vs 裝修
如果是新建：只有外殼 shell? 包含內部？地基整地要做？
如果是老建物裝修：什麼裝修程度？
4. 是否需要帶上 Prevailing Wage ([Prevailing Wage 規則](./PREVAILIING_WAGE.md))?

公家案
Prevailing Wage 規則：[Prevailing Wage 規則](./PREVAILIING_WAGE.md)
1. 做什麼項目？
2. 該項目什麼種類？
3. 動員幾次？
4. 是否需要 Traffic control?
